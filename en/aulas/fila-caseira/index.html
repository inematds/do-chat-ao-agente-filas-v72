Lesson 3 · 20 min

A Homegrown Queue in 30 Lines

Before the bot, you’ll see the whole idea in a short script from the jornada-agentes repository: four folders, one task at a time, resume after Ctrl+C, and failures kept separate with the reason.

  2. 2/5

    The script moves the file here before calling the agent. If you press Ctrl+C or the computer crashes, it stays here, which makes it possible to resume.

  3. 3/5

    feito/

    It worked (exit code 0 and a non-empty response): the final file contains the request, a line with ---, and the agent’s response.

  4. 4/5

    falhou/

    It failed or the response was empty: the file goes here with the exit code and what the agent printed. The queue moves on to the next task.

  5. 5/5

    Running it again only picks up what’s left

    At startup, the script returns anything left in rodando/ to entrada/. Anything already in feito/ is never redone.

Click each folder. The key is rodando/: the task only leaves that folder when it finishes, moving to feito/ or falhou/.

03 · The script and how to use it

It’s in ferramentas/fila-caseira.sh in the jornada-agentes repository. Both engines run through your subscription.

Terminal · set up and run
git clone https://github.com/inematds/jornada-agentes.git
cd jornada-agentes
mkdir -p fila/entrada
echo "Summarize in 5 lines what a task queue is." > fila/entrada/01.md
echo "List 3 risks of leaving an agent running on its own." > fila/entrada/02.md
./ferramentas/fila-caseira.sh fila          # default engine: claude
./ferramentas/fila-caseira.sh fila codex    # or codex
Inside fila-caseira.sh (shortened for reading)
mkdir -p "$PASTA/entrada" "$PASTA/rodando" "$PASTA/feito" "$PASTA/falhou"

# resume: anything left in "rodando" (crash, Ctrl+C) goes back to the queue
for f in "$PASTA"/rodando/*.md; do [ -e "$f" ] && mv "$f" "$PASTA/entrada/"; done

for f in "$PASTA"/entrada/*.md; do
  [ -e "$f" ] || { echo "empty queue"; break; }
  nome=$(basename "$f")
  mv "$f" "$PASTA/rodando/$nome"          # picks up the task (only one at a time)
  saida=$(claude -p "$(cat "$PASTA/rodando/$nome")" < /dev/null 2>&1); rc=$?
  if [ $rc -eq 0 ] && [ -n "$saida" ]; then
    # request + --- + response go to feito/
  else
    # request + ERROR (rc) + output go to falhou/
  fi
done

  1. Creates the four folders (running it again won’t break anything).
  2. Returns anything left in rodando/ to entrada/.
  3. Picks up one file at a time and moves it to rodando/ before calling the agent.
  4. Exit code 0 and a non-empty response: feito/. Otherwise: falhou/ with the exit code.
  5. At the end, counts how many are in each folder.
  • Receives requests through Telegram, not just from files.
  • Five queues with different limits, and automatic retries.
  • A deadline for each task and a chat notification when it’s done.
  • An approval gate in the middle of flows.
